# Developer 平台导航与应用切换初版

状态：`IMPLEMENTED / LOCAL_VERIFIED / VISUAL_REVIEW_PENDING`。

用户试用版本工作区后要求稳定最外层结构：进入应用前后保留同一平台导航和应用切换方式，避免从小卡片突然进入多层配置。功能职责已同步[页面结构](../page-architecture.md)，不固定样式参数。

## 交付范围

- 固定窄顶栏：平台名称、默认应用栏目、爬虫配置；没有首页栏目。标题返回应用列表，登录入口仍保留独立会话流程。
- 持续应用切换列表：当前应用标记、显式按钮展开/收起、键盘 Enter/Escape 与触控入口；悬浮、离开、失焦或点击外部均不再自动展开/收起。展开覆盖内容，不改变主内容占位。
- 展开锚定当前应用，选择应用时锚定刚点击的应用并自动收起；紧凑列表按真实滚动边界归位，不能保留顶部空白。不使用 inline style、运行时样式表或降低 CSP。缓冲仅在有应用的展开态提供，紧凑态不含缓冲高度，两态手动滚动均限制在真实内容及分页控制范围。
- 未选择应用而直接收起时先淡出，再恢复展开前紧凑列表位置并淡入；不伴随位移，Escape 采用同一路径。快速重新展开会取消未完成的淡入计时，尊重 reduced-motion。Ctrl/Meta 等新标签点击不收起当前工作区。
- 应用内概览、版本与发布、公开资料改为内容区局部导航，不再与外层应用切换争用同一层级。应用切换仍受编辑器离页保护。
- 独立默认范围的生成类型列表读取与显式分页，原完整应用筛选页保留。不请求不存在的爬虫 API、不新增业务写入。

## 会话与数据生命周期

稳定工作区根部拥有完整 Session 清理；各资源和侧栏保留独立读取 attempt。叶子 provider 保留原离页清理语义，只豁免仍由工作区拥有的导航 query root，整个 Session 退场无豁免。会话换代不重挂 Session 查询观察者，旧代 queries 精确清理，新代侧栏/详情重新建立。应用资源拒绝时侧栏摘要也清理，监听精确旧 Query 对象的回收并禁用常驻观察者，防止移除缓存后自动重建请求。空数据、正在请求和已清理待明确重读分开。

原应用/Tester 查询单测隔离新常驻导航的独立请求，以保持其受控序列；新侧栏测试不 mock 生成客户端或 Session transport，覆盖完整 React Router→同源 client 的合成响应流程。它们不是已发布镜像 E2E。

## 验证与边界

显式开关修订后，侧栏 15 项组件和 11 项几何测试通过；覆盖两种收起路径、正常滚动、选中项展开锚点、顶部空白校正、浏览器因高度变化产生的滚动、快速重新展开、修饰键点击及原会话/权限护栏。工作区 1138 项 Vitest（Developer 364）、工作区严格类型与 16 项构建/CSP Node 回归通过；Developer 生产构建、独立性、72 份 brief、App registry 与 diff 检查通过。首次几何修订测试有 1 项失败：合成输入的展开滚动值与预期 Y 不对应，修正该输入后保留原位置/边界断言通过。

此前悬浮首版新增 17 项，工作区 1128 项 Vitest（Developer 354）及默认 377 项 Node 通过，real/privacy/build-policy 类型与全生产构建通过；这些是上一阶段记录。本次未重跑 default published-latest 真实全量，旧实链 spec 的登录入口/重复名称定位等仍需随新导航适配，不能据普通测试宣称已兼容全部浏览器矩阵。

首轮 337 项回归有 15 项失败：新增请求消耗旧单测 mock 序列，且 provider 换代重挂导致 Session 观察者再次读取。隔离导航请求后仍有 3 项失败，移除 provider 的无必要换代 key、仅重建私有 attempt 后原 86 项 Application/Tester 测试通过。新增侧栏测试还发现拒绝回收后的自动重建请求与 idle/pending 表达问题，修正为明确停止观察、显式重读；未删除旧权限/代际护栏或用快照隐藏故障。

实际浏览器动画、少量与大量应用在不同视口下的观感仍待用户试用；前轮浏览器工具访问本地预览受策略限制，不绕过限制运行其他浏览器控制。几何测试使用合成 DOM 尺寸，不等同实际布局验收。原 backend 数据与本地绑定保留，网络写入仍默认关闭；未修改 Gateway/Auth/App，未 commit/push，不关闭整体 UC/goal。

本地 `https://developer.localhost:37117/applications` HTTP 200，新构建已由原静态服务读取；监听仍为 loopback，未恢复 NetBird 暴露。Vite future-native-loader 与大 chunk 警告仍存在，未屏蔽。
