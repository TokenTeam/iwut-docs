# UC-CONSOLE-016：查看与编辑本人账号资料

状态：`ACCEPTED`，2026-10-30，按用户持续goal的自主设计、接受和实施授权登记；实现与证据见[接入记录](../implements/2026-10-30-own-account-profile.md)，不由接受状态宣称交付完成。

## 目标与依赖

普通已登录用户在独立账号页查看并明确编辑自己主动提供的资料，不要求Developer或Reviewer资格。两个Console共用编辑组件，但各自保留独立Session、请求和缓存；资料不是应用公开资料、邮箱凭据、学校认证或权限授予。

权威业务来源为 Auth [UC005](../../auth-center/use-cases/UC-AUTH-005-edit-own-user-profile.md) 与[查询契约](../../auth-center/query-contracts/user-profile-editing.md)。固定API `6fea3db` 已有用户资料完整值类型，Gateway `9d6a27f` 为 `GetOwnProfile`、`GetProfileEditingSchema`、`EditOwnProfile` 提供双surface普通入口；不新增直连Auth或透传Session的BFF通用代理。

## 页面组织

- 两端提供独立全页 `/account/profile`，从全局账号入口进入，不放在任何应用下，不把进入账号页解释为拥有管理权限。
- 分别读取本人完整快照与编辑目录。目录只用于字段名称、说明、输入类型及约束；字段全部可选，不根据浏览器、邮箱、学校数据或其它资料自动填充。
- 已有资料与当前可编辑字段同页组织。目录不存在的旧字段保留原类型和值，只允许明确删除，不为其发明可重新设置的定义。目录失败不伪装为空目录，也不隐藏仍可读的本人快照与纯删除能力。
- 类型涵盖STRING、INTEGER、BOOLEAN、DATE、STRING_SET、ACADEMIC_GRADE，按正式options提供选择；不把false、0、空填写和删除混作同一状态。未知未来类型只读保留并可删除，不擅自转成字符串。

上述未知类型指目录中的未来valueType仍可用当前正式消息无损读取已有值；若后端返回客户端不支持的新wire oneof或畸形快照，则整次读取失败关闭，不丢掉未知分支后伪造完整资料，也不基于残缺值构造删除命令。
- 当前年级按服务端schema的学年与保存锚点推算，并区分最后确认内容与当前派生展示。跨阶段或年级重新确认是用户明确编辑，不静默更新资料。学年不可确认时禁用该类设置，其它合法编辑与纯删除按后端能力独立处理。

本用例不提供教务登录/导入、图片加载、资料公开预览、第三方授权或管理员代填；不能以方便填写为由采集学校密码或原始教务响应。

## 编辑与提交

本页填写仅在当前组件内存中保留，不自动保存到服务端或本地持久存储。用户修改后查看本次设置/删除的字段并明确提交；命令仅包含实际选择的set/remove与已读expectedRevision，不完整替换未涉及字段。原始文本保留前导零、空格与大小写；空字符串不等于删除，删除必须明确选择。

设置、保留、删除有明确区别；同一key不能同时设置和删除。STRING_SET按正式选项选择成员，提交完整集合；ACADEMIC_GRADE提交本次观察的学年，不提交服务端confirmedAt。不向用户展示或要求手填内部revision、时间戳、Auth ID或权限字段。

提交期间冻结该批次，防止重复命令；结果成功后以返回完整快照建立已保存基线，changed=false如实展示。回执须符合原目标、正式结构、版本与时间约束；不得用一张局部表单把未涉及的历史值清掉。“还原填写”只恢复本次已确认基线，不回滚服务端。离页时提示本地未提交或结果待核对，不通过卸载事件上传。

冲突、学年变化、网络/5xx/畸形成功或未知结果均停止写入，保留本地差异并提供明确重读。当前值与本地修改可对照，用户明确采用新的资料和目录后才可重新编辑/提交；不自动把未知操作重放，也不因当前值碰巧一致断言原请求一定成功。纯删除不因目录错误被强制阻止，仍携带有效本人基线。

## 私有生命周期与验收

组件与查询绑定当前Console的Session代际，失效/禁用/失权优先退场；新身份、旧响应、同key新Query及旧Query的数据变化均不能恢复或覆盖旧个人资料。schema与值是独立读取，不拼成不存在的事务快照；命令版本和学年由服务端最终确认。

验收包括六种类型与正式选项、无值/false/0/前导零、未知旧key删除、空目录与目录失败的纯删除、学年派生与明确重新确认、无关字段保持、no-op、并发冲突/未知不重放、本地还原/离页与Session/Query保护。真实镜像专项以专用普通USER在实际页面完成set/remove及权威读回，不用seed或mock代替成功链；生产字段目录是否启用按实际服务响应确认，测试目录不能冒称生产配置已交付。
