# UC-CONSOLE-008：版本与发布工作台及版本编辑

状态：`ACCEPTED`，2026-10-27。

## 用户目标与范围

开发者在当前应用内查看正式、灰度和测试分发情况，找到版本并在整页工作区创建或编辑草稿。结构遵循[页面规划](../page-architecture.md)；具体排版允许通过初版迭代，不属于本 UC 的约束。

后端权威为 App [UC002 创建](../../app-center/use-cases/UC-APP-002-create-application-version.md)、[UC003 更新](../../app-center/use-cases/UC-APP-003-update-draft-application-version.md)、[UC034 读取](../../app-center/use-cases/UC-APP-034-query-owned-application-versions.md)。发布与 Tester 语义只引用页面规划所列后端用例，不在此重定义。Console UC003 的读取语义继续适用；本 UC 扩展其只读交付边界，不追溯修改历史实现登记。

## 页面职责

1. 版本与发布主页保留 `/applications/:appId/versions`，按 RPC major 选择 Publication 摘要，查看始终展开的三个槽位；概览复用相同只读信息。没有发布分区时明确空态，不虚构 major 或指针；槽位数据时间独立于版本列表。
2. 版本列表按服务端顺序累计分页，提供单审核状态筛选、新建入口和状态引导。没有全局状态排序、多状态和全文查询 API，不对已加载页排序冒充全量。
3. 新建和已有版本使用同一整页编辑结构，分组展示入口、运行兼容性、权限声明和回调，不使用大型编辑浮窗。技术 ID、revision 和诊断信息次级呈现。
4. 已提交、通过、拒绝的版本内容只读，最新审核单独展示；拒绝后恢复、提交和放弃命令仍留后续有界增量。2026-10-28 用户授权接通下文发布设置，不把它扩展为其他写能力。
5. 测试成员与链接从同级“测试配置”选项卡进入已有应用级测试管理页；不嵌入版本表单，不引入版本归属关系。

## 前端规则

<a id="br-cvw-001"></a>
### BR-CVW-001：资源创建与保存状态

新建填写只存在当前页面内存，不称为服务端草稿。完整有效后明确创建一次，成功才替换 URL 进入资源模式；创建响应丢失时结果未知，不能自动重试生成重复版本。已有 DRAFT 的有效完整快照防抖、串行保存，携带强 If-Match。输入不完整时保留填写并标记未保存，不发无效局部 PATCH；服务端仍是字段与权限校验权威。

保存反馈至少区分未创建、未保存、正在保存、已保存、冲突与结果未知。后台响应不覆盖更新的输入；错误不自动重放写请求。未知写需明确读回核对，确认后才重新建立基线。

<a id="br-cvw-002"></a>
### BR-CVW-002：重置与离页

新建“清空填写”仅清当前表单；已有草稿“还原至本次打开时”使用进入工作页时的内容，明确确认可能写回服务端，再走相同并发控制。它不是撤销服务端历史或 REJECTED 恢复命令。未保存、在途或未知结果离页提示；换会话或拒绝访问仍立即清理私有数据，不让提示阻挡安全退场。不依赖卸载保存，不默认持久化私有表单。

<a id="br-cvw-003"></a>
### BR-CVW-003：独立快照与能力边界

Publication 与 Version 使用各自正式读取及 asOf；不把 APPROVED 等同上线，不把三槽位当作审核状态，不用当前筛选猜槽位版本名称。按 ID 精确进入工作页即可，不无界补查。共享导航不改变当前会话、应用权限、迟到响应拒绝和严格 CSP 边界。

未开放的 Gateway DEVELOPER 命令不走 BFF 临时代理、普通后端路由或浏览器 Session header 绕过。接入状态必须明显，未发送写入时不显示成功。

## 首版交付与外部依赖

### 2026-10-30：版本写入与审核提交增量

用户重新激活自主实现 goal，允许自行接受并实施本增量。Gateway `9d6a27f` 已为本 UC 的创建、更新、提交、恢复与放弃显式开放 DEVELOPER；对应本地镜像已交付。普通链仍逐次由 App 复核资格、管理关系与状态；不得因前端显示某状态就跳过服务端校验。

- 接入创建与自动保存后，保存状态仅由有效 ACK 确认；正常页面不要求用户理解 revision。冲突或未知结果暂停写入，明确读回当前版本、保留尚未确认输入；以用户确认的当前快照开启新编辑基线，不能自动覆盖他人改动或重发原写。
- DRAFT 工作页提供明确“提交审核”，等待有效内容保存完成且以实际读取/保存的 revision 作为前置。送审不是自动保存的一部分，至少一次明确确认，提交期间停止编辑；不能把尚未保存表单当已提交 snapshot。引用 App [UC004](../../app-center/use-cases/UC-APP-004-submit-application-version-review.md)。
- REJECTED 可以明确恢复为 DRAFT，再进入同一编辑页；SUBMITTED/APPROVED 保持内容只读。恢复引用 App [UC006](../../app-center/use-cases/UC-APP-006-restore-rejected-version-to-draft.md)，不构造本地状态跳转。
- 放弃未提交草稿需独立确认，成功回到版本列表并重新读取；不将放弃解释为任意删除、撤回审核或回滚发布。引用 App [UC035](../../app-center/use-cases/UC-APP-035-abandon-unsubmitted-application-version-draft.md)。
- 送审/恢复 ACK 后重读真实版本与管理摘要，两份读取均成功后才提供使用当前状态重新打开工作页的入口。放弃成功后返回版本列表并重读列表与管理摘要，不再要求已放弃版本的详情成功。未知或冲突只允许明确读取核对，不自动重放；ACK 已确认而读回失败须分别表达。新会话、访问拒绝、应用切换、迟到ACK与私有表单清理沿用原边界，安全退场优先于普通离页提示。

新入口在本地镜像接入、实际路由验证后开启；UI/合成验证与真实创建/保存/送审结果分别记录，不把镜像和配置存在当作业务成功。

### 2026-10-28：发布设置有界增量

用户明确授权接通正式、灰度、测试发布设置。后端语义引用 App [UC007](../../app-center/use-cases/UC-APP-007-place-approved-version-in-test-slot.md)、[UC020](../../app-center/use-cases/UC-APP-020-manage-stable-publication-slot.md)、[UC021](../../app-center/use-cases/UC-APP-021-manage-grey-rollout.md)、[UC036](../../app-center/use-cases/UC-APP-036-clear-test-publication-slot.md)，不复制资格、DNS、Scope、OAuth 等判定规则。

- 在“版本与发布”中直接点击渠道卡片打开短配置浮窗，明确选择渠道与 exact RPC major，不再另设卡片内“发布设置”按钮。没有分区时必须由用户输入 major；首次设置正式或测试可创建分区，不假设 major=1。大量版本内容编辑仍在独立整页工作区，不移入此浮窗。
- 再次打开已有发布渠道时默认选中当前引用。浮窗显示版本选择、所选版本基本信息与版本工作页跳转；基本信息从正式版本详情按选中 ID 惰性读取，并保留独立数据时间。当前引用不在候选已加载页时只精确读取它，不自动遍历全部候选。打开、关闭或切换版本只读取，不触发设置或清空；正常关闭恢复卡片焦点，在途／未知结果仍要求先核对。
- 候选只来自正式 APPROVED 查询，显式累计分页；按已读取的 RPC 范围辅助筛选，不把已加载页当全部，也不以客户端筛选代替后端资格复查。
- 设置／替换、清空均由用户确认后单次发送，不自动保存、不自动重放。携带打开设置时捕获的共享 Publication revision；首次创建使用预期不存在，空分区仍使用其正 revision。DELETE 使用契约规定的 query 前置值，不发送伪造 JSON body 或 If-Match。
- 灰度比例按百分比输入、精确换算为万分比（0.01%–100%）。现有管理摘要只有整数百分比，不据此回填精确原比例；设置时要求明确输入目标值。缺少 Stable 基线时提示先设置 Stable；存在 Grey 时不提供可成功清空 Stable 的假承诺。
- 写入成功后读取当前 Application 摘要；不把写回执直接冒充管理查询快照。冲突、已拒绝或结果未知均暂停提交，保留输入，提供明确读回；未知写即使读回目标已满足，也不据此宣称之前操作一定成功。用户确认当前状态后才开启新基线。
- 换会话、换应用、访问拒绝和迟到响应继续使用原私有消费边界；设置内容仅存页面内存，离页时提示在途／待核对结果，安全退场优先。

Gateway `5efc9d5` 为六条现有命令开放 DEVELOPER surface，运行镜像已更新为 published latest `b8a5b26f…`，Admin 不开放。不额外启用版本创建／更新、审核提交或 Tester 写入。新增官方 API 生成子集仍固定 `6fea3db`；UI、合成验证和真实业务联调分别登记，不用镜像路由存在宣称业务成功。

API 固定 6fea3db。2026-10-27 首版时 Gateway 的版本创建和更新尚无 DEVELOPER surface，因此当时默认关闭网络写入，仅提供整页结构与填写；不以当时的环境开关证明服务端授权。2026-10-30 后的命令接入以上方增量为准，真实证据见[写入接入](../implements/2026-10-30-developer-write-workspace.md)和[审核、恢复与发布闭环](../implements/2026-10-30-version-review-publication-loop.md)，不再将首版限制作为当前实现状态。
